📚 Dubz Library System (DarkRP)

A simple library system for DarkRP featuring a fully functional Librarian job, interactive bookshelves, and a checkout system.

🔹 Features:

Placeable bookshelves with physical book slots
Pickup / place books using a weapon-based system
Locked & unlockable books (must purchase before reading)
Fully working checkout desk for librarians
Librarian job support (free access to all books)
Custom book UI with pages and readable content
Configurable books, prices, and rewards

🔹 Gameplay Flow:

Find or place books on shelves
Bring locked books to the checkout counter
Librarian processes the purchase
Read your books anytime after unlocking

🔹 Includes:

Bookshelves
Checkout desk
Book boxes (spawn random books)
Book weapon system
Custom UI reader

Perfect for RP servers looking to add passive income, roleplay interaction, and a unique librarian role.
